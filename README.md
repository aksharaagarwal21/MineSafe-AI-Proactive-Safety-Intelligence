# MineSafe AI · Proactive Mining Safety Intelligence

A safety monitoring dashboard for underground mines that analyses sensor data to spot anomalies, forecast readings and predict risk before incidents happen.

## Features

- Live and historical readings for environmental sensors such as methane
- Time-series decomposition and correlation analysis
- Anomaly detection with z-scores and Isolation Forest
- Forecasting with gradient boosting and risk prediction with a random forest classifier
- What-if scenario analysis
- Alert system with configurable thresholds, miner and zone status, and shift reports

> Sensor data is generated by a simulator (`backend/data_simulator.py`) with trends, seasonality and injected anomalies; it is not connected to real mine sensors.

## Tech stack

**Frontend:** React · Vite · Tailwind CSS · Recharts
**Backend:** Python · Flask · scikit-learn · NumPy · SciPy

## Run locally

Start the API (port 5001):

```bash
cd backend
pip install -r requirements.txt
python app.py
```

In another terminal, start the dashboard:

```bash
npm install
npm run dev
```

The dashboard forwards `/api` requests to the Flask server.
